### Sentinel — Website Security Assessment Tool

Sentinel is my flagship cybersecurity engineering project: a passive website security health checker designed to identify observable security weaknesses without performing intrusive testing.

I'm currently developing the system around areas such as TLS and certificate inspection, HTTP security-header analysis, and cookie security checks.

The project is also helping me strengthen my Python, FastAPI, HTTP, TLS, testing, debugging, and secure software engineering fundamentals.

**Technologies:** Python, FastAPI, React, Vite, Tailwind CSS
